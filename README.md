# 🇵🇰 Explore Pakistan Tour

**Discover the Land of Beauty**

Explore Pakistan Tour is an AI-assisted tourism website that showcases Pakistan's beautiful destinations, rich culture, and useful travel guidance.

## 🌟 Features
- Search for travel destinations
- Filter destinations by category
- View detailed destination information
- Explore Pakistan's photo gallery
- Open images in a lightbox
- Read visitor reviews and ratings
- Discover cultural information and travel tips

## 🛠️ Technologies
- HTML
- CSS
- JavaScript

## 🤖 AI Tool Used
ChatGPT — used for prompt guidance, website development assistance, and improving the project.

## 🎯 Project Purpose
The purpose of this project is to introduce Pakistan's natural beauty, historical places, cultural heritage, and tourism opportunities through a user-friendly website.
